- **근거:** Forgejo는 DevOps/협업 도구 관심 분야에 해당하는 self-hosted Git 포지이나, 운영 중인 프로덕션 스택이 없으므로 즉시 패치 대상 아님
- **액션:** Forgejo를 운영 중이라면 16.0.4로 즉시 업그레이드 필요 — 아닐 경우 RCE 취약점 원인(릴리즈 노트) 읽고 self-hosted Git 포지 보안 패턴 파악
