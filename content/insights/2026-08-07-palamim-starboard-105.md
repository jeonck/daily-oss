- **근거:** macOS Dock 옆에 항상 고정되는 터미널 앱 — 개발자 도구(CLI/터미널) 카테고리에 해당하며, Swift로 작성된 실제 코드(Package.swift, Sources)가 존재하는 완성도 있는 저장소
- **액션:** macOS 환경에서 `git clone https://github.com/palamim/starboard && cd starboard && swift build` 로 빌드 후 Dock 옆 고정 터미널 동작 확인
